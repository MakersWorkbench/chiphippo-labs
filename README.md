# Chip Hippo Labs

Circuit labs (`.chiphippo`) from the Electronics Fundamentals series at [The Makers Workbench](https://themakersworkbench.com). Each file is a complete [Chip Hippo](https://github.com/MakersWorkbench/chiphippo-web) circuit with the parts, wiring, and instruments set up for the lesson it belongs to.

## Using a lab

1. Open the Chip Hippo editor at [circuits.themakersworkbench.com](https://circuits.themakersworkbench.com).
2. Open the `.chiphippo` file from the `labs/` folder.
3. Run the circuit and follow the matching article.

Files ending in `-v2` and `-v3` are later revisions of the same circuit; the article embeds the latest one.

## What is here

The labs for the Electronics Fundamentals articles: How Voltage Works, How Electric Current Works, How Electrical Resistance Works, How Ohm's Law Works, and How Kirchhoff's Circuit Laws Work. Labs are added as each article is published.
